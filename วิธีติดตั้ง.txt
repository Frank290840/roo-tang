รู้ตังค์ · Roo Tang  —  วิธีขึ้นเว็บและติดตั้งลงมือถือ
==========================================================

ในโฟลเดอร์นี้มี
  index.html              ตัวแอป
  manifest.webmanifest    ข้อมูลแอป (ชื่อ ไอคอน สี) ทำให้กด "ติดตั้ง" ได้
  sw.js                   ทำให้เปิดแอปได้แม้ไม่มีเน็ต
  icon-*.png, apple-touch-icon.png, favicon-32.png, icon.svg   ไอคอนแอป

แอปต้องอยู่บนเว็บ https ก่อน มือถือถึงจะติดตั้งได้
วิธีที่แนะนำ: GitHub Pages (ฟรี ใช้ได้ตลอด)


ขั้นที่ 1  ขึ้นเว็บด้วย GitHub Pages  (ทำครั้งเดียว ใช้คอมพิวเตอร์จะง่ายที่สุด)
-----------------------------------------------------------------------
1. สมัครบัญชีที่ https://github.com  (ชื่อผู้ใช้จะอยู่ในลิงก์แอป เช่น frank-oe)
2. กดปุ่ม + มุมขวาบน → New repository
     Repository name:  roo-tang
     เลือก Public
     กด Create repository
3. ในหน้า repository กดลิงก์ "uploading an existing file"
4. แตก zip นี้ แล้วเลือกไฟล์ทั้งหมดในโฟลเดอร์ (ทุกไฟล์อยู่ชั้นเดียว ไม่มีโฟลเดอร์ย่อย)
   อัปโหลด → กด Commit changes
5. ไปที่ Settings → Pages
     Source: Deploy from a branch
     Branch: main  /  (root)   → Save
6. รอ 1–2 นาที จะได้ลิงก์แอป
     https://ชื่อผู้ใช้.github.io/roo-tang/


ขั้นที่ 2  ติดตั้งลงมือถือ
------------------------
iPhone (ต้องใช้ Safari)
  1. เปิดลิงก์แอปใน Safari
  2. กดปุ่มแชร์ (สี่เหลี่ยมมีลูกศรขึ้น)
  3. เลือก "เพิ่มไปยังหน้าจอโฮม" → เพิ่ม
  ไอคอน "รู้ตังค์" จะขึ้นบนหน้าจอ เปิดแล้วเต็มจอเหมือนแอปทั่วไป

Android (Chrome)
  1. เปิดลิงก์แอปใน Chrome
  2. กดเมนู ⋮ มุมขวาบน → "ติดตั้งแอป" (หรือ "เพิ่มลงในหน้าจอหลัก")
  3. กดติดตั้ง


ส่งให้ทีม
--------
ส่งลิงก์ https://ชื่อผู้ใช้.github.io/roo-tang/ ในกลุ่ม LINE
แต่ละคนติดตั้งเอง ตั้งบัญชีและ PIN ของตัวเอง
ข้อมูลเงินเดือน โน้ต และ swipe เก็บในมือถือของแต่ละคน ไม่มีใครเห็นของคนอื่น
(ตัวแอปไม่มีข้อมูลส่วนตัวของใคร มีแค่แผนกะระดับทีม)


อัปเดตแอปเวอร์ชันใหม่
-------------------
1. เปิด repository roo-tang บน GitHub → Add file → Upload files
2. ลากไฟล์ใหม่ทับ (ส่วนใหญ่คือ index.html และ sw.js) → Commit changes
3. รอ 1–2 นาที แล้วปิด–เปิดแอปในมือถือ 1–2 ครั้ง จะได้เวอร์ชันใหม่
ข้อมูลในมือถือของทุกคนยังอยู่ครบ


ข้อควรรู้
--------
- ถ้าลบแอปออกจากหน้าจอ หรือล้างข้อมูลเบราว์เซอร์ ข้อมูลในแอปจะหาย
  ให้ใช้เมนู บัญชี → สำรองข้อมูล เก็บไว้เป็นระยะ
- iPhone: แอปที่ติดตั้งจากหน้าจอโฮม กับที่เปิดใน Safari เก็บข้อมูลแยกกัน
  ให้ใช้จากไอคอนบนหน้าจอโฮมเป็นหลัก
- เปิดแอปได้แม้ไม่มีเน็ต ยกเว้นตอนเปิดเว็บ Swipe เพื่อดึงข้อมูล
